House Price Prediction

📌 Project Overview

This project uses Machine Learning to predict house prices based on important features such as square footage, number of bedrooms, and number of bathrooms.

The project demonstrates the implementation of a Linear Regression model using Python and Scikit-learn.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

📊 Features

The model uses the following features to predict house prices:

- Square Footage
- Number of Bedrooms
- Number of Bathrooms

🤖 Machine Learning Model

A Linear Regression algorithm is used to train the model and predict house prices.

The project includes:

1. Creating and preparing the dataset
2. Selecting features and target values
3. Splitting the data into training and testing sets
4. Training the Linear Regression model
5. Making predictions
6. Evaluating the model
7. Visualizing actual vs. predicted prices

📈 Results

The project generates an Actual vs. Predicted price visualization to compare the model's predictions with the actual house prices.

"Actual vs Predicted" (actual_vs_predicted.png)

📂 Project Files

- "house_price_prediction.py" — Python source code for the house price prediction model.
- "actual_vs_predicted.png" — Visualization comparing actual and predicted prices.

▶️ How to Run

Clone or download this repository and run:

python house_price_prediction.py

Make sure the required Python libraries are installed:

pip install pandas numpy matplotlib scikit-learn

🎯 Objective

The objective of this project is to demonstrate a basic supervised machine learning regression workflow for predicting house prices.
